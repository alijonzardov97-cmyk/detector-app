# STT Defense — приложение к металлоискателю

Список приборов, консоль под модель, телеметрия, обновление прошивки по
воздуху, звук и вибрация в телефоне, журнал находок и карта с флажками.
Интерфейс на семи языках, выбор — на первом экране.

## Что лежит в этой папке

    build.gradle.kts         корневой файл сборки
    settings.gradle.kts      состав проекта
    gradle.properties        параметры сборки
    .github/workflows/       автосборка APK на GitHub
    app/                     сам модуль приложения
      build.gradle.kts       версия, зависимости, минимальный Android
      src/main/AndroidManifest.xml
      src/main/java/com/alijon/detector/
        MainActivity.kt      экраны и переходы между ними
        Ble.kt               связь с прибором и передача прошивки
        Protocol.kt          протокол: телеметрия, уставки, настройки
        Feedback.kt          звук, вибрация, журнал находок
        Map.kt               карта, координаты, автоматические флажки
        Prefs.kt             пользовательские настройки
        Runtime.kt           фоновый режим, GPS по факту находки, датчик света
        Appearance.kt        темы оформления
        Strings.kt           все надписи на семи языках
        Ota.kt               поиск и загрузка прошивки из релизов
      src/main/res/          иконки, цвета, темы

Обёртки Gradle (`gradlew`) здесь нет намеренно: сборка идёт на GitHub, а там
Gradle ставится отдельным шагом. Если собираете у себя в Android Studio, она
создаст обёртку сама при первом открытии проекта.

## Сборка APK без Android Studio

1. Залейте содержимое этой папки в репозиторий на GitHub.
2. Вкладка **Actions** → **Build APK** → **Run workflow**.
3. Через несколько минут в результатах появится артефакт
   `STT-Defense-<версия>-run<номер>`. Внутри — `STT-Defense-<версия>.apk`.

Каждый push в `main` пересобирает APK сам. Номер прогона в имени артефакта
нужен, чтобы не поставить на телефон старую сборку, не заметив этого.

## Где что настраивается

Репозиторий с прошивками — в начале `MainActivity.kt`:

```kotlin
private const val REPO = "alijonzardov97-cmyk/detector-app"
```

Пароль на запись настроек прибора — там же:

```kotlin
private const val SETTINGS_PIN = "1986"
```

Версия приложения — в `app/build.gradle.kts`, поля `versionCode` и
`versionName`. Имя APK берётся из `versionName` автоматически.

## Важно про версии прошивки

Версия, которую прибор сообщает о себе, берётся только из `FW_VERSION` в
скетче. Имя файла в релизе на неё не влияет. Если они разойдутся, приложение
скажет, что версия не сменилась, хотя образ встал правильно.
