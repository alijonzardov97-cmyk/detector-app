# Detector Console

Приложение для импульсного металлоискателя: список приборов, консоль под модель,
обновление прошивки по воздуху, звук и вибрация в телефоне, журнал находок.

## Сборка без Android Studio

1. Создайте на GitHub репозиторий и залейте туда содержимое этой папки.
2. Вкладка **Actions** → workflow **Build APK** → **Run workflow**.
3. Через 3–5 минут в результатах запуска появится артефакт `detector-console-apk`.
   Скачайте, распакуйте, установите `app-debug.apk` на телефон
   (понадобится разрешить установку из неизвестных источников).

Каждый push в `main` пересобирает APK автоматически.

## Что поправить под себя

`app/src/main/java/com/alijon/detector/MainActivity.kt`

```kotlin
private const val REPO = "alijon/pi-detector"   // репозиторий с прошивками
```

`app/src/main/java/com/alijon/detector/Protocol.kt` — таблица `Models`:
идентификатор модели, её название и список уставок. Одна запись на модель,
та же строка должна приходить от прибора в паспорте.

## Прошивки

GitHub Releases того же или отдельного репозитория. Имя файла строго:

```
PI-1-1.4.0.bin        <модель>-<версия>.bin
```

Модель из имени файла сверяется с моделью прибора — чужую прошивку залить нельзя.

## Что должна уметь прошивка

Сервис Nordic UART. В рекламных пакетах — service data под тем же UUID,
строка `МОДЕЛЬ|СЕРИЙНИК|ВЕРСИЯ`, чтобы список приборов заполнялся до подключения.

Подробности протокола — в шапке `Protocol.kt`.
